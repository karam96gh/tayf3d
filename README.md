# موقع طيف — Tayf 3D

موقع تعريفي بخدمات «طيف». فكرته وحدة: شعار طيف معمول من زجاج حقيقي بيكسر الضو لألوان الهوية الخمسة، وبيتغيّر شكله وأنت عم تنزل بالصفحة.

## ليش هو سريع

- **بدون مكتبات 3D:** المشهد كله shader واحد بـ WebGL 2 (رسم بالأشعة raymarching)، والجافاسكربت كلها حوالي 7 KB مضغوطة.
- **خط واحد:** Alexandria، والمتصفح بيحمّل بس الأوزان والحروف يلي بيحتاجها.
- **دقة تكيّفية:** إذا الجهاز ضعيف، دقة الرسم بتنزل لحالها وبيضل ناعم.
- **ما في شاشة تحميل:** المحتوى HTML جاهز من أول لحظة، والزجاج بيظهر بهدوء أول ما يكون جاهز.
- إذا الجهاز ما بيدعم WebGL 2، بتطلع صورة للزجاج بداله.

## الملفات

| الملف | شو فيه |
| --- | --- |
| `index.html` | كل النصوص |
| `src/styles.css` | التصميم (الألوان بأول الملف) |
| `src/main.ts` | وين بيروح الزجاج بكل قسم (جدول `WIDE` للكمبيوتر و `NARROW` للموبايل) |
| `src/prism/shader.ts` | الزجاج نفسه: الشكل، الانكسار، تشتّت الألوان، والإضاءة |
| `src/prism/Prism.ts` | تشغيل المشهد، السحب بالماوس، والدقة التكيّفية |
| `src/config.ts` | رقم الواتساب والإيميل والانستغرام |

## التشغيل

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # النسخة النهائية بمجلد dist/
```

## النشر

كل `git push` على فرع `main` بيبني الموقع وبينشره على GitHub Pages لحاله (`.github/workflows/deploy.yml`)، على الدومين tayf3d.com.

## التعديل السريع

- **رقم الواتساب:** حطه بـ `src/config.ts` بحقل `whatsapp` (مثال `963912345678`)، وكل أزرار «ابدأ مشروعك» بتفتح واتساب برسالة جاهزة.
